## Save as PDF (recommended)

1. Open `MINTZER-UI-DESIGN-BRIEF.html` in **Google Chrome**
2. Press `Ctrl+P`
3. Destination: **Save as PDF**
4. Margins: Default
5. Enable **Background graphics**
6. Save as `MINTZER-UI-DESIGN-BRIEF.pdf`
