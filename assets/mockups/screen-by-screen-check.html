Out of scope Do not build
If something feels missing, it is almost always one of these (not a missing main screen):
  • Ticket detail — list exists, tap does nothing
  • Appearance — Light/Dark toggle, no System radio sheet
  • Payout — simplified fields vs full UPI confirm / bank IFSC
  • Raise ticket — not the guided category wizard
  • In-app Place order — hint, not PerkPay 3 tabs (see place-order-locked.html)
  • Language — EN/HI toggle via snack, no picker overlay
  • Help / tutorials / notification prefs — Profile rows snack only
  • Timer expired overlay — optional v1, not in demo
