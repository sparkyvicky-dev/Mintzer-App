FIX GOOGLE RESULTS FOR “mintzer”
================================
Google copies titles and text from four public listings. Changing this
repo alone does not update Google until those live pages change, then
Google recrawls (usually a few days; request indexing to speed it up).

What Google shows today, and the fix
------------------------------------
1) mintzer.in — “with your Credit Cards”
   Cause: old homepage had no <title>, broken “Earn” headline.
   Fix: upload the new marketing site (already has a real title).
   Title Google should then use:
     Mintzer — Card deals. Earn paid to your bank

2) Google Play — “Mintzer - Let's make money”
   Cause: Play Console app name + old description (typos, emoji).
   Fix: paste the Play copy below. Package must stay com.mintzer.

3) App Store — same cheap name
   Cause: App Store Connect listing name.
   Fix: paste the Apple copy below. Apple URL slug will stay
   mintzer-lets-make-money; that is normal and cannot change.

4) app.mintzer.in — “Welcome to Mintzer! Please sign-in…”
   Cause: Google indexed the admin login.
   Fix: noindex the subdomain (do not delete newapp).

Do these in order
-----------------
A. Hostinger — new mintzer.in  (see UPLOAD-ME.txt)
   Extract into public_html only. Never touch newapp / beta.
   Confirm https://mintzer.in/ title is the new one, and
   https://app.mintzer.in/ still loads.

B. Hostinger — hide admin from Google
   File Manager → public_html/newapp/public/.htaccess
   Paste the 4 lines from:
     app-mintzer-in-noindex/PASTE-AT-TOP-OF-HTACCESS.txt
   at the TOP of that file. Save.
   Optional extra (same folder):
     public_html/newapp/resources/views/login/login.blade.php
   Add this line inside <head>:
     <meta name="robots" content="noindex, nofollow">

C. Google Search Console (search.google.com/search-console)
   Property: mintzer.in
   - URL inspection → https://mintzer.in/ → Request indexing
   - Also request: /contact /privacy /terms
   Removals → hide https://app.mintzer.in/ (and prefix if offered)
   If app.mintzer.in is a separate property, add it, then hide.

D. Play Console → Mintzer (com.mintzer) → Main store listing
   Paste App name, Short description, Full description below.
   Submit. Do not change the package name.

E. App Store Connect → Mintzer → App Information / version
   Paste Name, Subtitle, Description below. Submit for review
   if Apple requires a version for listing text.

Flipkart & Amazon card deals. Accept, order, earn paid to your bank.
